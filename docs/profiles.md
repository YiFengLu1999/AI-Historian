# Execution profiles

AI Historian has one semantic method and two execution profiles. They share the same evidence model and A1–A9 responsibilities, but they differ in how cross-document material is scoped at runtime.

| Aspect | Evaluation implementation | Scalable full-text implementation |
| --- | --- | --- |
| Package path | `ai_historian.profiles.evaluation` and `experiments/` | `ai_historian.profiles.scalable_fulltext` |
| Primary purpose | Reproduce the paper's controlled evaluation | Process complete texts for the Westlake Historian workflow |
| Input scope | Bounded case packets prepared for Experiments 1 and 2 | Full documents and multi-document collections |
| Cross-document scope | Candidate scope is already small and controlled | Runtime retrieval builds small `episode_packet` scopes from full texts |
| A8 verification | Quote- and context-grounded 10B judgement | The same core 10B judgement, invoked on retrieved mini-scopes and merged back into the full run |
| Command | `uv run aih` | `uv run aih-fulltext` |
| Main priority | Evaluation fidelity and frozen-result traceability | Context scalability, recall, resumability, and application export |
| Reported paper scores | Directly represented by the frozen evaluation artifacts | Referenced through the evaluation profile |

## Shared method

Both profiles preserve source sentences and stable identifiers, construct TimeBlocks, separate narrative order from chronological order, verify candidate cross-text relations before temporal transfer, and normalize accepted evidence into traceable temporal ranges. The semantic roles A1–A9 therefore remain the same.

## How the full-text profile handles context limits

The platform-oriented implementation supplies A8 with bounded scopes generated by its runtime-scope layer:

1. reads the complete Step 10 TimeBlock outputs;
2. retrieves promising cross-document windows using lexical or optional embedding similarity;
3. constructs compact, anchor-aware `episode_packet` candidates with limited surrounding context;
4. creates temporary mini-run scopes and invokes the same core 10B evidence-verification stage;
5. deduplicates accepted evidence and merges it into the original full-text TimeBlocks; and
6. continues through single-document stabilization, temporal-graph propagation, A9 normalization, and application export.

This context-management and deployment adaptation preserves AIH's underlying historical-evidence method.

## Interpretation boundary

The paper's headline Experiment 1 result—86.2% MicroIoU on 244 eligible ranges across six *Shiji* cases—comes from the archived evaluation implementation. Experiment 2 diagnoses structured intermediate reasoning. The scalable full-text implementation enables readers to apply the same AIH method to longer corpora. Result comparisons should identify the corresponding execution profile.
